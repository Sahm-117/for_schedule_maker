# ContextSaver

Saves a short summary of every AI coding session into your project, so the next session, or another AI tool, picks up where you left off.

Works with: Claude Code · other agents

## Install

**Claude Code:** copy this folder to `~/.claude/skills/context-saver/` (so the file sits at `~/.claude/skills/context-saver/SKILL.md`), then start a new session. Claude picks it up when it's relevant, or you can call it by name.

**Other AI agents (Codex, Cursor, Aider, Gemini and others):** open the `.md` file and paste it into your agent as instructions, or save it wherever your tool keeps its rules or custom commands. Each file is written in plain steps, so any capable coding agent can follow it.

## Before you start

Needs Node.js 18+ and the `claude` CLI signed in. For a full install on a new machine, paste SETUP-PROMPT.md into your agent.
